### 💬 পর্ব ১: রিপোজিটরি তৈরি ও টোকেন জটিলতা
* **ব্যবহারকারীর প্রশ্ন/নির্দেশ:**  
  * *"আমার গিটহাব একাউন্টে (Rimon4jb22) এই প্রজেক্টটি রিলিজ করতে চাচ্ছি। নতুন এসইও অপটিমাইজ রিপোজিটরি খোলো এবং প্রথম ভার্সন a001 আপলোড করো।"*
* **আলোচনা ও সমাধান:**
  * ইউজার প্রথমে একটি Fine-grained PAT প্রদান করেন। কিন্তু GitHub API রেসপন্স দেয়: Fine-grained PAT দিয়ে স্বয়ংক্রিয়ভাবে নতুন ইউজার রিপোজিটরি তৈরি করা নিষিদ্ধ (403)।
  * বিষয়টি ব্যবহারকারীকে টেকনিক্যালি ব্যাখ্যা করার পর ইউজার একটি Classic PAT (`repo` স্কোপসহ) দেন।
  * স্বয়ংক্রিয়ভাবে `Auto-Cut-and-Polishing-Tool` রিপো তৈরি করা হয় এবং ১৭টি হাই-ট্রাফিক এসইও কীওয়ার্ড যুক্ত করা হয়।
